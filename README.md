# До последнего лея / Până la ultimul leu

**RU.** Сатирический браузерный симулятор налогового инспектора в Кишинёве. 4 рабочих дня, план 800 000 лей, очередь из бабушек с петрушкой, маршрутчиков, винодела «для себя» и людей в тёмных очках. Штрафуй, проверяй, отпускай — или бери конверты, пока антикоррупция не постучала в кабинет 13.

**RO.** Simulator satiric de inspector fiscal din Chișinău, în browser. 4 zile de lucru, un plan de 800 000 de lei și o coadă de bunici cu pătrunjel, rutieriști, un vinificator «pentru consum propriu» și oameni cu ochelari negri. Amendezi, verifici, ierți — sau iei plicuri, până bate Anticorupția la ușa biroului 13.

## Играть / Joacă

https://forgepilotmur.github.io/inspector-md/

Один файл `index.html`, без сборки и зависимостей: можно просто открыть его в браузере. Звуки синтезируются через Web Audio. Языки: русский и румынский.

Un singur fișier `index.html`, fără build și fără dependențe: îl poți deschide direct în browser. Sunetele sunt sintetizate cu Web Audio. Limbi: rusă și română.
